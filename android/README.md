# Wandero for Android

Нативная mobile-first версия экранов `M10–M16` из Figma: исследование карты, карточка места, конструктор и готовый маршрут, навигация, каталог и детали прогулки.

```bash
GRADLE_USER_HOME=/tmp/wandero-gradle gradle --offline -p android assembleDebug
```

APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.
